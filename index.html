What it does

🔌

Any provider

OpenAI, Anthropic, Gemini, DeepSeek, Ollama or any OpenAI-compatible API. Bring your own keys and model names; requests go straight to the provider.

📁

Project mode

Connect a folder and the agent reads and writes files, uses git, builds and runs tests — Xcode, SwiftPM, Gradle, Cargo, Go, Node, Python and more.

🧠

Three-level memory

Global, project and thread memory that survives between sessions.

🌐

Curl-Chappie

An HTTP client for debugging backends: per-thread host allow-list, secrets kept in Keychain and never shown to the model, repeatable scenarios.

📄

Documents and PDF

Reads Word, Excel, PowerPoint and PDF, including embedded images and scanned pages.

🛡️

Safety gates

Access levels for terminal and git, command checks, loop guard and timeouts.
