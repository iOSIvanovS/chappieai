# Contributing

ChappieAI is developed by a single author, and **pull requests are not accepted**. They will be closed without review. This keeps the copyright of the code in one place.

## What is welcome

- **Bug reports.** Open a [GitHub issue](https://github.com/iOSIvanovS/chappieai/issues) with the app version, macOS version, steps to reproduce and what you expected. Do not paste API keys, tokens or passwords.
- **Ideas and questions.** Open a GitHub issue.
- **Security problems.** Please write privately to [@serebanium](https://t.me/serebanium) on Telegram rather than opening a public issue.

Response times are not guaranteed.

## Forking

The code is GPL-3.0, so you are free to fork and change it for your own use. If you publish a fork, follow the [name and logo policy](TRADEMARK.md).
